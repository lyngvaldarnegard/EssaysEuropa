# Privacy Policy

Last updated: 23 October 2026

This policy describes how EssaysEuropa Poster handles information when using Google authorization and YouTube API Services.

EssaysEuropa Poster is developed and operated by Sigurd Bigset as a personal application for uploading his own videos to his own YouTube channel. It is not offered as a public account-registration service.

## Information accessed and processed

For its authorized upload functionality, the application processes:

- The video files selected by the owner for upload.
- Video titles, descriptions, and publication settings supplied by the owner.
- Google OAuth access tokens and, where issued, refresh tokens.
- Upload responses from YouTube, such as the uploaded video's identifier and upload status.

The application requests authorization for its YouTube publishing functionality. It does not request access to Gmail messages, Google contacts, or Google Drive files.

The application does not receive or store Google account passwords.

## How information is used

Information is used only to authenticate authorized requests, upload the selected content to YouTube, apply the owner's selected publication settings, and report the result of the upload.

Google user data is not used for advertising, sold, or used to train generalized artificial intelligence or machine-learning models.

The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements:

https://developers.google.com/terms/api-services-user-data-policy

## Storage and protection

The application runs in the owner's own computing environment. OAuth credentials and any retained upload information are stored locally, not in this public website or its GitHub repository.

Access tokens, refresh tokens, passwords, and private video files must not be committed to the public repository.

The owner restricts access to the computer and files containing authorization credentials. Only information needed to operate the publishing functionality is retained.

## Sharing and third parties

Selected video files, their accompanying metadata, and authorized API requests are sent to Google and YouTube to perform the requested upload.

The application does not sell or rent personal information or share Google user data with advertising companies or data brokers.

This documentation website is hosted using GitHub Pages. GitHub may process technical request information when someone visits it, in accordance with its own privacy statement:

https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

Google and YouTube process information under Google's Privacy Policy:

https://policies.google.com/privacy

## Retention and deletion

Locally stored authorization credentials are retained while the application remains connected and in use.

The owner can delete locally stored credentials and retained API response data. Deleting a local source video or disconnecting the application does not delete a video already uploaded to YouTube. Uploaded videos can be managed or deleted through YouTube.

Requests to delete application-held Google user data can be sent to slbigset@gmail.com. Such data will be deleted as soon as possible and within seven calendar days of the request. This does not delete information held independently by Google or YouTube.

## Revoking Google account access

Authorization can be revoked through the Google Account connections page:

https://myaccount.google.com/connections

Select EssaysEuropa Poster and remove its access.

After revoking access, stop using the integration and delete its locally stored credentials and retained API data. A new authorization is required before the application can access the account again.

## Cookies and advertising

The application does not use Google user data for targeted advertising.

This documentation website does not intentionally add advertising cookies or analytics trackers. Its hosting provider may process technical information as described in its privacy statement.

## Changes to this policy

This policy will be updated if the application's functionality or data-handling practices change. The date above identifies the latest revision.
