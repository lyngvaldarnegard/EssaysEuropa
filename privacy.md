# Privacy Policy

Last updated: 25 October 2026

EssaysEuropa Poster is a personal application operated under the EssaysEuropa project for uploading original videos to the owner's YouTube channel.

The application uses YouTube API Services. This policy explains how it handles information used for that functionality.

## Information accessed and processed

The application processes:

- Video files selected by the owner for upload.
- Video titles, descriptions, and publication settings supplied by the owner.
- Google OAuth access tokens and, where issued, refresh tokens.
- Responses from YouTube relating to uploads, including video identifiers, upload status, and error information.

The application requests access for its YouTube publishing functionality. It does not request access to Gmail messages, Google contacts, or Google Drive files.

The application does not receive or store Google account passwords.

## How information is used

Information is used to authorize API requests, upload selected videos, apply the owner's chosen publication settings, and report upload results.

Google user data is not sold, used for advertising, or used to train generalized artificial intelligence or machine-learning models.

The application's use and transfer of information received from Google APIs will adhere to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including its Limited Use requirements.

## Storage and security

The application runs on the owner's own computer.

Authorization credentials and any retained upload information are stored locally. They are not published on this website or committed to its public GitHub repository.

The owner restricts access to the computer and files containing credentials. Only information needed for the application's publishing functionality is retained.

## Sharing

Selected videos, accompanying metadata, and authorized API requests are transmitted to Google and YouTube to carry out uploads.

The application does not sell or rent personal information or share Google user data with advertising companies or data brokers.

Google and YouTube process information in accordance with the [Google Privacy Policy](https://policies.google.com/privacy).

This documentation website is hosted by GitHub Pages. GitHub may process technical information about visits under the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Retention and deletion

Authorization credentials are retained locally while the application remains connected and in use. Retained API responses are kept only while needed to operate or troubleshoot the application.

The owner can delete locally stored credentials and retained API data.

Deletion requests may also be sent to lyngvaldarnegard@gmail.com. Application-held Google user data covered by such requests will be deleted as soon as possible and within seven calendar days.

Deleting local files or disconnecting the application does not delete videos already uploaded to YouTube. Those videos can be managed or deleted through YouTube.

## Revoking access

Access can be revoked through the [Google Account connections page](https://myaccount.google.com/connections).

Select EssaysEuropa Poster and remove its access.

After revoking access, stop using the integration and delete its locally stored authorization credentials and retained API data. A new authorization is required before the application can access the account again.

For assistance with revocation or deletion, contact lyngvaldarnegard@gmail.com.

## Cookies and advertising

This documentation website does not intentionally add advertising cookies or analytics trackers.

GitHub, as the hosting provider, may process technical request information as described in its privacy statement.

The application does not use Google user data for targeted advertising.

## Changes

This policy will be updated if the application's functionality or data-handling practices change.
